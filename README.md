# 🍰 Casa Marcê — Confeitaria Fina & Ateliê Artesanal

> E-commerce moderno, elegante e mobile-first desenvolvido para a doceria artesanal **Casa Marcê**, combinando design premium em alta gastronomia com fechamento prático de pedidos via WhatsApp.

🔗 **Acesse o projeto online:** [Casa Marcê no GitHub Pages](https://SEU-USUARIO.github.io/casamarce/)

---

## 📸 Sobre o Projeto

O site foi projetado com inspiração visual de grandes marcas de alta chocolateria (como Cacau Show e confeitarias boutique), priorizando uma paleta sofisticada em **verde musgo profundo** e **dourado champagne**.

A plataforma oferece uma vitrine virtual interativa com foco em conversão rápida: o cliente navega pelo cardápio com fotos reais, filtra por categorias, adiciona produtos à sacola com cálculo em tempo real e finaliza o pedido pronto direto no WhatsApp da confeiteira.

---

## ✨ Funcionalidades Principais

- 🧁 **Catálogo Completo & Reativo:** 12 delícias cadastradas com fotos reais locais, preços, selos de destaque e descrições detalhadas.
- 🏷️ **Filtros Dinâmicos por Categoria:**
  - 💼 Kits Corporativos
  - 🥥 Caseirinhos & Salgados
  - 🍓 Tarts & Doces Finos
  - 🎂 Bolos & Pães Artesanais
  - 🎁 Caixas & Presentes
- 🔍 **Busca em Tempo Real:** Pesquisa instantânea por nome ou ingredientes tanto no desktop quanto no mobile.
- 💼 **Módulo de Kits Corporativos (B2B):**
  - Banner exclusivo para encomendas corporativas e endomarketing.
  - Card com badge **"Sob Encomenda"** e botão de montagem personalizada via atendimento consultivo no WhatsApp.
- 🛍️ **Sacola Lateral Interativa (Offcanvas Cart):**
  - Adição e remoção de itens com controle de quantidade (+/-).
  - Cálculo instantâneo de subtotal e total.
  - Barra de progresso para ganho de **Mimo Especial** (meta a partir de R$ 100,00).
  - Campo de cupom de desconto promocional (`MARCE10` para 10% OFF).
- 📲 **Checkout via WhatsApp:** Montagem automática da mensagem com lista de produtos, quantidades, subtotais e valor final estimado.
- 📱 **Design Responsivo (Mobile-First):** Experiência adaptada para celulares, tablets e desktops.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído com arquitetura leve e alto desempenho, dispensando frameworks pesados ou processos de build complexos:

| Tecnologia | Finalidade |
| :--- | :--- |
| **HTML5** | Estrutura semântica, acessibilidade e organização do documento. |
| **Tailwind CSS (CDN)** | Estilização utilitária moderna, layout responsivo e paleta de cores personalizada (*Verde Musgo & Dourado Champagne*). |
| **JavaScript (ES6+)** | Lógica de estado do carrinho, filtros de categorias, busca em tempo real, cupons e integração com API do WhatsApp. |
| **Lucide Icons** | Biblioteca de ícones vetoriais leves e elegantes. |
| **Google Fonts** | Tipografia clássica (*Playfair Display* para títulos e *Plus Jakarta Sans* para leitura). |
| **GitHub Pages** | Hospedagem estática contínua e gratuita na nuvem. |
